# Steam Guard Lite для macOS

Минимальное офлайн-приложение с компактным окном, которое генерирует
5-символьные коды Steam Guard для нескольких аккаунтов из их `shared_secret`.
Код обновляется каждые 30 секунд.

## Запуск

Готовое приложение находится в `dist/Steam Guard Lite.app`. Перетащите его в
папку «Программы» и запустите. При первом запуске импортируйте свой `.maFile`
или вставьте `shared_secret` вручную.

Каждый импорт `.maFile` добавляет аккаунт в выпадающий список над кодом. Имя
берётся из `account_name`; если его нет, используется имя файла. Выберите
аккаунт в списке и нажмите «Скопировать код» (или Enter). Код и таймер сразу
обновятся для выбранного аккаунта. Последний выбор сохраняется после выхода.

Повторный импорт того же аккаунта обновляет его данные без дубликата. Вручную
можно добавить аккаунт, указав имя и `shared_secret`. Кнопка «Удалить выбранный
аккаунт» удаляет только выбранный аккаунт после подтверждения.

Для массового добавления нажмите «Импорт из папки…» и выберите папку с
`.maFile`. Приложение обработает все файлы с этим расширением непосредственно
в выбранной папке (без вложенных папок). Существующие аккаунты обновятся без
дубликатов. Повреждённые или недоступные файлы будут пропущены; в конце появится
отчёт о добавленных аккаунтах, повторных импортах и пропущенных файлах.
Список сохраняется в Связке ключей одной операцией после обработки всей папки.

Имена, секреты и последний выбор хранятся в Связке ключей macOS. Приложение
работает офлайн и импортирует только имя, SteamID (если есть) и `shared_secret`;
сессионные токены и остальные секреты из `.maFile` не сохраняются.

При обновлении старый секрет автоматически переносится под именем
«Сохранённый аккаунт». Импортируйте его `.maFile` ещё раз, чтобы вместо этого
появилось настоящее имя: аккаунт обновится, второй экземпляр не добавится.

Если код не принимается Steam, включите автоматическую синхронизацию даты и
времени в системных настройках macOS.

## Сборка из исходников

```sh
./test.sh
./test-ui.sh
./build.sh
```

Тесты используют вымышленные аккаунты и хранилище в памяти: ваши `.maFile`
и Связка ключей не затрагиваются. `test-ui.sh` дополнительно проверяет окно
и переключение аккаунтов через реальные элементы Cocoa.

Нужны только macOS и установленный Xcode Command Line Tools. Приложение собрано
на Objective-C/Cocoa без сторонних зависимостей, поэтому бинарник получается
очень небольшим.

## Важно

`shared_secret` и `.maFile` позволяют генерировать коды доступа. Не отправляйте
их другим людям и не добавляйте `.maFile` в публичный репозиторий.
