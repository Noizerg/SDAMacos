# Steam Guard Lite для macOS

Нативное приложение с компактным окном, которое генерирует
5-символьные коды Steam Guard для нескольких аккаунтов из их `shared_secret`.
Код обновляется каждые 30 секунд и генерируется офлайн. Дополнительно можно
подтверждать ожидающие обмены выбранного аккаунта через интернет.

## Запуск

Готовое приложение находится в `dist/Steam Guard Lite.app`. Перетащите его в
папку «Программы» и запустите. При первом запуске импортируйте свой `.maFile`
или вставьте `shared_secret` вручную.

Каждый импорт `.maFile` добавляет аккаунт в выпадающий список над кодом. Имя
берётся из `account_name`; если его нет, используется имя файла. Выберите
аккаунт в списке и нажмите «Скопировать код» (или Enter). Код и таймер сразу
обновятся для выбранного аккаунта. Последний выбор сохраняется после выхода.

Повторный импорт того же аккаунта обновляет его данные без дубликата. Вручную
можно добавить аккаунт, указав имя и `shared_secret`. Кнопка «Удалить выбранный
аккаунт» удаляет только выбранный аккаунт после подтверждения.

Для массового добавления нажмите «Импорт из папки…» и выберите папку с
`.maFile`. Приложение обработает все файлы с этим расширением непосредственно
в выбранной папке (без вложенных папок). Существующие аккаунты обновятся без
дубликатов. Повреждённые или недоступные файлы будут пропущены; в конце появится
отчёт о добавленных аккаунтах, повторных импортах и пропущенных файлах.
Список сохраняется в Связке ключей одной операцией после обработки всей папки.

Имена, секреты и последний выбор хранятся в Связке ключей macOS. Из `.maFile`
импортируются имя, SteamID (если есть), `shared_secret`, `identity_secret`,
`device_id` и, при наличии, сессия Steam Community (`SteamLoginSecure` или
`AccessToken`, `SessionID`). Код отзыва аутентификатора и `RefreshToken` не
сохраняются. Полученная при входе веб-сессия также сохраняется в Связке ключей.

## Подтверждение обменов

1. Выберите аккаунт и нажмите «Сделки выбранного аккаунта…».
2. Если аккаунт добавлен в старой версии приложения, сначала импортируйте его
   `.maFile` заново: старые версии не сохраняли `identity_secret` и `device_id`.
3. В окне сделок нажмите «Войти в Steam». Войдите в нужный аккаунт на странице
   `steamcommunity.com` внутри приложения, затем нажмите «Я вошёл — продолжить».
   Кнопка «Скопировать код Steam Guard» копирует актуальный код этого аккаунта.
   Пароль вводится на странице Steam; приложение его не считывает и не хранит.
   Сессия другого SteamID не будет сохранена для выбранного аккаунта.
4. Нажмите «Обновить», выберите ожидающий обмен и проверьте сводку. Для полной
   проверки предметов и получателя можно нажать «Открыть обмен в Steam».
5. Нажмите «Подтвердить выбранный обмен…» и подтвердите действие в диалоге.

Поддерживаются мобильные подтверждения обменов (`type=2`). Это подтверждение
уже созданного/принятого обмена, а не принятие произвольных входящих предложений.
Объявления на Торговой площадке и изменения безопасности аккаунта не
подтверждаются. Автоматического подтверждения всех сделок нет.

При истечении сессии войдите в Steam снова. Если запрос подтверждения оборвался,
обновите список и проверьте состояние обмена в Steam перед повторной попыткой.
Коды для входа продолжают работать без интернета.

Запросы подтверждений реализованы по формату
[SteamAuth](https://github.com/geel9/SteamAuth/blob/master/SteamAuth/SteamGuardAccount.cs)
и [node-steamcommunity](https://github.com/DoctorMcKay/node-steamcommunity/blob/master/components/confirmations.js).
Это неофициальный интерфейс Steam Community, который Valve может изменить.

При обновлении старый секрет автоматически переносится под именем
«Сохранённый аккаунт». Импортируйте его `.maFile` ещё раз, чтобы вместо этого
появилось настоящее имя: аккаунт обновится, второй экземпляр не добавится.

Если код не принимается Steam, включите автоматическую синхронизацию даты и
времени в системных настройках macOS.

## Сборка из исходников

```sh
./test.sh
./test-ui.sh
./build.sh
```

Тесты используют вымышленные аккаунты, ответы Steam и хранилище в памяти:
ваши `.maFile`, Связка ключей и реальные сделки не затрагиваются. Запросы в
интернет из тестов не отправляются. `test-ui.sh` дополнительно проверяет окна
аккаунтов и сделок через реальные элементы Cocoa.

Нужны только macOS и установленный Xcode Command Line Tools. Приложение собрано
на Objective-C/Cocoa без сторонних зависимостей; для страницы входа используется
системный WebKit.

## Важно

`shared_secret` и `.maFile` позволяют генерировать коды доступа. Не отправляйте
их другим людям и не добавляйте `.maFile` в публичный репозиторий.
